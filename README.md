# Ramdeo Unisex Salon website

A simple static website for Ramdeo Unisex Salon, based on the supplied Udyam Registration Certificate.

## Hostinger deployment

Import the Git repository in Hostinger and choose **Deploy as static**. The repository root contains `index.html`; no build command or output directory is required.

## Local preview

```powershell
python -m http.server 4183
```

Open `http://127.0.0.1:4183`.

## Content notes

- Public business information comes from the supplied `ramdeo.pdf` certificate.
- Personal identity, banking, financial, employment and social information are excluded.
- Website photographs are AI-generated representative visuals, not documentary photographs of the actual premises, staff or clients.
- Current services, appointment requirements, availability, pricing, products and results must be confirmed directly with the business.
